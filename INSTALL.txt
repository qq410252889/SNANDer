Windows 10 64 位：

1. 将基于 CH347F/T 芯片的 USB 编程器插入 USB 接口。
2. 下载并运行 CH341PAR.EXE，然后点击 INSTALL（安装驱动）。
3. 在控制台模式（cmd）下使用 SNANDer.exe...

Linux Ubuntu 64 位：

1. 将 SNANDer 复制到 /usr/local/bin 目录。
2. 将 40-persistent-ch347.rules 复制到 /etc/udev/rules.d 目录。
3. 执行 udevadm control --reload-rules 重启 udev 服务。
4. 在控制台模式下使用 SNANDer。
